# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-11-09

### Added

- A Spanish-language introductory web development course covering seven HTML and CSS lessons, with videos, explanations, and CodePen activities.
- Starter files and completed examples for lessons 2–7, covering HTML structure, text and links, CSS styling, layout and borders, common errors and practices, and a final video-game card.

### Changed

- Updated lesson durations, video URLs, and practice links to reflect the course materials.
